# Features for a quieter explorer

## 1. Return to the exact step

**User need.** An analyst leaves a step to check a role score and wants to continue reading in the same place.

**Interaction.** Add “Copy step link” beside the atomic ID. The link identifies the graded role, task, subtask and step. Opening it expands the correct branch and focuses the step heading. Browser Back restores the previous selection.

**Acceptance check.** Two steps with the same source ID in different branches produce different links. A removed step opens its role with a short availability message.

## 2. Compare two grade profiles

**User need.** A department lead wants to understand what changes between an associate and a senior practitioner.

**Interaction.** Put “Compare grades” inside a role family with multiple profiles. Start with the two profile sizes and shared workflows. Show differing controls and responsibilities first. A disclosure reveals shared material.

**Acceptance check.** A grade with only two illustrative steps shows its coverage and validation status. Missing records are labelled “unrecorded” so a gap in the catalogue cannot be mistaken for a change in responsibility.

## 3. Keep a research shortlist

**User need.** A researcher wants to investigate several workflows without keeping several tabs open.

**Interaction.** Allow a role or step to be saved from its detail view. A single dashboard link opens the shortlist. Store references on the current device and resolve current catalogue details when opened.

**Acceptance check.** Saving the same record twice creates one entry. Reloading preserves it. Removing the final item clears the dashboard link. Unavailable items can still be removed.
