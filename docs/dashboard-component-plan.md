# Proposed dashboard components

Place new components below Suggested explorations and Research tools, alongside or after Leading departments. Keep the illustrated role explorer as the first action. Introduce one component at a time so the dashboard remains easy to scan.

## 1. Continue from your shortlist

Show up to three saved roles or atomic steps, with the parent department or role alongside each title. Use the existing device shortlist and catalogue lookup. Selecting a row opens the exact record. Hide this module when there are no saved items. Check that removing the last item clears the module.

## 2. Compare grades within a role family

Offer one family with two or more grades. Show the grade labels and recorded step counts side by side. Open the existing comparison with both profiles selected. Counts describe catalogue coverage and carry the sample label when applicable. Hide the module if a valid pair cannot be resolved.

## 3. Work shared across roles

Feature one recurring atomic step with its distinct role-family count and up to two example roles. Reuse the matching rule from Patterns & outcomes and link to its filtered results. Require at least two distinct families. Check that multiple grades in the same family count once.
